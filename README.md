# LLM Applications

A curated collection of practical LLM applications built with Python, focused on solving real business, operational, and product problems using Large Language Models.

This repository was created to demonstrate applied AI engineering skills for international software engineering, AI engineering, LLM engineering, and automation opportunities.

## Problem Solved

Many companies want to apply AI to real workflows, but struggle to move from simple prompts to useful internal tools.

This repository demonstrates how LLMs can be used to support common business needs such as resume analysis, ticket triage, document assistance, code review, text classification, and prompt engineering workflows.

## Business Value

These projects show how LLM-powered systems can help teams:

* Reduce manual analysis work
* Improve support ticket triage
* Extract insights from documents
* Review code faster
* Standardize classification workflows
* Improve decision support
* Build reusable AI workflows
* Turn unstructured text into structured outputs

The goal is to show practical LLM engineering, not only isolated AI experiments.

## Projects Overview

### 1. AI Resume Analyzer

Analyzes resume content and returns strengths, weaknesses, detected technologies, and improvement suggestions.

**Use case:** recruiting, candidate screening, resume improvement, and HR automation.

**Business value:** reduces manual resume review time and provides structured feedback.

### 2. AI Ticket Classifier

Classifies support tickets by category, priority, and sentiment.

**Use case:** customer support, internal helpdesk, SaaS support teams, and issue triage.

**Business value:** helps teams prioritize urgent issues faster and route tickets more efficiently.

### 3. AI Document Assistant

Answers questions about a provided document or text using local logic or LLM-based reasoning.

**Use case:** internal knowledge assistants, document search, policy review, and operational support.

**Business value:** helps users extract relevant information from documents without reading everything manually.

### 4. AI Code Reviewer

Reviews code snippets and highlights potential bugs, maintainability risks, and concrete improvements.

**Use case:** developer productivity, code quality, pull request support, and learning.

**Business value:** helps developers identify issues earlier and improve code maintainability.

### 5. Prompt Engineering Lab

A reusable prompt library for summarization, classification, analysis, generation, and automation scenarios.

**Use case:** prompt testing, reusable AI workflows, structured outputs, and LLM experimentation.

**Business value:** improves prompt consistency and helps transform vague AI usage into repeatable workflows.

## Quick Start

Enter one of the project folders:

```bash
cd ai-ticket-classifier
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the project:

```bash
python main.py --mode local --text "I cannot access my account and this is urgent."
```

Each project folder contains its own README with specific usage instructions.
