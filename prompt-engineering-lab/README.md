# Prompt Engineering Lab

A collection of tested prompts for practical LLM tasks.

## Prompt Categories

## Summarization
- "Summarize the following text in 5 bullet points with plain language."
- "Create an executive summary focused on business impact and risks."

## Classification
- "Classify this support message into category, urgency, and sentiment as JSON."
- "Label this feedback as positive, neutral, or negative with rationale."

## Analysis
- "Analyze this resume and return strengths, gaps, and improvement actions."
- "Review this code snippet and list potential bugs and refactoring opportunities."

## Generation
- "Draft a professional follow-up email based on these notes."
- "Generate 3 versions of a product description for different audiences."

## Automation
- "Extract action items, owners, and deadlines from this meeting transcript."
- "Convert this unstructured ticket into a normalized JSON schema."

## Prompting Notes
- Define role and objective clearly.
- Specify output format (JSON, bullets, table).
- Constrain scope and style.
- Provide examples for consistency.
